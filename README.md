# Rico Herrmann · mindric lab

Apps, automations and fixes, built end to end by one person.

I build software and AI-driven workflows, mostly solo, with tools like Claude Code, local LLMs (Ollama) and ComfyUI in the loop. Some of it ships as its own product, some solves a specific problem for someone else. When something breaks, I want to know why.

**What I do**

- **Build** – web apps, desktop tools and small products (Next.js, Expo / Tauri, Electron, single-file tools)
- **Automate** – AI workflows and local setups: LLMs on your own hardware, ComfyUI pipelines, scripts against repetitive work
- **Solve** – debugging, refactoring, stuck projects, data recovery, security basics
